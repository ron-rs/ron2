# RON2 Showcase

A simple example demonstrating the ron2 ecosystem.

## Features Demonstrated

- `#[derive(Ron)]` for automatic serialization/deserialization
- Loading configuration from a `.ron` file
- Validating against generated schemas
- Pretty-printing with customizable formatting
- Recursive schema generation for editor support

## Running

The package `example-showcase` has two binaries; run them from anywhere in the
workspace:

```bash
cargo run -p example-showcase --bin simple         # load, validate and print data/game.ron
cargo run -p example-showcase --bin write_schemas  # write schemas for the LSP and `ron doc`
```

## Schema Output

`write_schemas` calls `GameConfig::write_schemas` to write every schema reachable
from `GameConfig` into `examples/showcase/schemas/`, named by type path
(`example_showcase::GameConfig` becomes `example_showcase/GameConfig.schema.ron`).
`data/game.ron` declares `#![type = "example_showcase::GameConfig"]`, so pointing
the LSP's `schemaDirs` at that directory enables completions for it.

## Files

```
showcase/
├── data/
│   └── game.ron                 # Sample configuration file
├── schemas/                     # Generated by write_schemas (git-ignored)
│   └── example_showcase/
│       ├── GameConfig.schema.ron
│       ├── WindowConfig.schema.ron
│       └── ...
└── src/
    ├── bin/
    │   ├── simple.rs            # Load, validate and pretty-print the config
    │   └── write_schemas.rs     # Write the schema files
    └── lib.rs                   # The config types
```
